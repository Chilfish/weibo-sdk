# 2026-10-22

## 归档脚本模块化

**触发**：`scripts/archive-user.ts` 已经有 1281 行，参数解析、日期切片、journal、并发补全、最终合并和顶层编排全部堆在一个文件里。每加一个开关或调整续跑语义都要在同一个文件里来回跳，难读也难测。

**判断**：

- **行为不变**：命令行参数、journal 文件格式、续跑规则、归档 JSON 结构全部保持原样，只调整代码组织。唯一顺带修掉的是 `buildConfig` 对 `--comment-order` 默认值的隐式依赖——现在缺省时自己回落到 `time`，单独调用也成立。
- **按职责拆模块**，不做框架级重写：继续用 `node:util` 的 `parseArgs`。续跑校验需要知道「用户显式传了哪些参数」，`parseArgs` 的 `tokens` 正好提供这个信息；换成 citty 反而要额外保留这层信息。
- **编排收进 `ArchiveJob`**：原来 `run()` 里的 `completed` / `retryTargets` / `attempted` / `pending` 窗口都是闭包变量，现在作为一次运行的状态集中在一个类里，`runner.ts` 只负责从命令行走到 job，再走到输出。
- **IO 与纯逻辑分开**：切片计划、配置校验、issue 归一化、去重、统计都是纯函数，单独成模块并补离线测试；文件读写只留在 `journal.ts` / `raw.ts`。

**改动**：

- 新建 `scripts/archive-user/` 目录，拆成 `index` / `runner` / `job` / `archive-one` / `output` / `journal` / `raw` / `config` / `cli` / `slices` / `time` / `concurrency` / `issues` / `types` / `constants`。
- 删除 `scripts/archive-user.ts`；`package.json` 的 `archive:user` 指向 `scripts/archive-user/index.ts`。
- 新增 `scripts/archive-user/README.md`：运行流程、参数、断点续跑、journal 结构、模块职责、修改指引与排障。
- 新增 `tests/unit/scripts/archive-user/` 七组离线测试，共 57 条，覆盖切片边界、CLI 解析与续跑校验、journal 截断修复与去重、raw sidecar、并发窗口、最终合并排序 / 统计 / issue 去重。
- 同步 `docs/README.md` 文档索引、`docs/engineering/archive-schema.md` 的脚本路径、`tests/TEST_INDEX.md` 与 `CHANGELOG.md`。
