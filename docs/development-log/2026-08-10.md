## 第二轮 Apple 视角设计审查

新增 [review-apple-design-2026-08-10](../reviews/review-apple-design-2026-08-10.md)。基于「npm 发布 + 真实下游」两个新事实重评（承接第一轮 review-2026-08-09）：

- **核心转变**：`ITweet` 从「响应形状」变成「磁盘格式」——改字段 = 破坏下游已归档数据。ABI 稳定性从口号变格式问题。
- **新问题组 K（下游契约）**：
  - K1 ITweet 无版本管理（`schemaDigest` 只检测上游漂移，不管理契约版本）
  - K2 版本策略与协议漂移耦合（下游集成文档 §3.1「主版本跟随协议漂移」= 下游被微博绑架）
  - K3 媒体 URL 一小时过期却被当长期存档（`ITweet.ts` 注释已意识，未当契约处理）
  - K4 归档流缺评论阶段（下游 core `Post.comments[]` 迁移无家可归）
  - K5 `normalizeTweet` 有损（`.passthrough()` 在 schema 层，`normalizeTweet` 只留固定形状）
  - K6 `platform:'node'` 未验证浏览器（下游 web-v3/monkey 在浏览器/油猴域内跑 sdk）
- **新问题组 R（归档硬化）**：
  - R1 `visitedMblogIds` 死重且 O(N²) 爆炸（无任何代码消费它去重）
  - R2 reposts 阶段 `collectTimelineMblogIds` 重放整个 timeline（测试证实翻两遍）
  - R3 无进度/ETA（「进度可追踪」是空话）
  - R4 单点失败全盘崩溃（无 skip/retry）
  - R5 page 翻页天花板 → 大号（实测 13581 条）「完整镜像」不成立，`searchProfile` 时间片是必要组件
- **升级/降级**：C3/E2/E5/F2/E4 升级（npm 发布后是对外 `.d.ts` 说谎 / 下游护城河）；F3 CLI 降级（有真实 persona）；C1/C2 确认已修复。
