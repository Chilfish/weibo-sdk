## 发布事故：npm publish 打包 `catalog:` 依赖 → 0.1.1 重发

**现象**：0.1.0 发布后，`npm i -g @chilfish/weibo-sdk@0.1.0` 报 `EUNSUPPORTEDPROTOCOL: Unsupported URL Type "catalog:"`。

**根因**：维护者手动执行的是 `npm publish`；npm 不解析 pnpm `catalog:` 协议，把 `"axios": "catalog:"` 等原样写进产物 `package.json`。同一源码用 `pnpm pack` 时依赖会被重写为 `^1.20.0` / `^0.2.2` / `^4.5.4`。

**处置**：

- `npm unpublish @chilfish/weibo-sdk@0.1.0 --force`（72 小时内、零依赖方），用 `pnpm publish` 重发 `0.1.1`。
- 核验：registry `dist-tags.latest = 0.1.1`；tarball `dependencies` 正常；临时目录安装后 `node dist/cli.mjs --version` → `0.1.1`。
- 新增 `scripts/verify-publish-tool.mjs`：`prepublishOnly` 检测 `npm_config_user_agent`，非 `pnpm` 直接失败（`npm run prepublishOnly` 已验证 exit 1，`pnpm run prepublishOnly` 通过）。
- 沉淀 [postmortem 010](../postmortem/010-npm-publish-catalog-protocol.md)，并同步 release checklist（禁止 `npm publish`、发布后解包核验依赖）。

**遗留**：

- registry 里还有 `0.0.0-stage`（02:25:40 发布的无依赖 / 无 bin 占位版本），当前 `latest` 已指向 `0.1.1`；npm 页面仍有 CDN 缓存，显示旧标签。
- 本机 `npm i -g` 因 `C:\ProgramData\npm` 权限失败（与包无关），改用 `npm i --prefix <tmp>` 完成安装核验。

## Cookie 支持文件路径（SDK + CLI）

**需求**：`cookie` 参数除了 header 串，还要能直接传完整文件路径，自动读取并解析 Netscape `cookies.txt` 或 header 串内容。

**改动**：

- 新增 `src/utils/cookieInput.ts`：`resolveCookieInput`（路径探测 + 读取 + 解析）+ `parseNetscapeCookies` / `parseCookieHeaderContent`（纯函数，可单测）。
- 解析规则：Netscape 7 列 TSV（支持 `#HttpOnly_`、跳过注释行与过期条目、同名后写覆盖），只保留 `weibo.com` / `weibo.cn` / `sina.com.cn` 域名；header 文件支持 `Cookie:` 前缀与多行；无有效条目 / 路径不存在 / 无微博 Cookie 抛 `InvalidConfigError`（`CONFIG_INVALID`，`context.path` 指路）。
- 浏览器安全：不静态 import `node:fs`，通过 `process.getBuiltinModule('node:fs')` 按需取用；浏览器环境退化为原样字符串（`dist/browser.mjs` 构建与导出面检查通过）。
- 接入点：`WeiboSDK` 构造时解析一次（避免每个 Service 重复读文件）；`AuthService` 兜底（直接构造也生效）；`FetcherService` 请求拦截器改用 `AuthService` 的解析结果；CLI `getCookie` 统一解析并在失败时打印友好错误 + exit 1。
- 测试：`tests/unit/utils/cookieInput.test.ts`（16 例）+ `AuthService` / `getCookie` 文件路径用例。
- 真实文件复核（本机 Netscape 导出）：解析出 6 条微博 Cookie（含 `SUB` / `SUBP` / `XSRF-TOKEN`），header 长度 517；`sdk.checkSession()` 返回 `true`，`whoami --cookie <path>` 退出码 0。

**门禁**：`pnpm test`（223 passed / 18 skipped）/ lint / build / browser-smoke（Node 侧）全绿。
