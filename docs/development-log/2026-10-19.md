## Cookie 来源收口（只读 `.env`）

**现象**：`.env` 已更新为新 Cookie，但 `whoami` 仍报 `Weibo session expired`。

**根因**：`process.loadEnvFile()` **不覆盖已存在的环境变量**；本机 `WEIBO_COOKIE` 环境变量为 514 字符旧值（`profile/detail` 返回 `ok:-100`），`.env` 为 517 字符新值（`ok:1`）。CLI 一直读到旧值。

**决策（维护者）**：Cookie **只从指定 `.env` 读取**（默认 `<pwd>/.env`），不再回退到环境变量；`--cookie` 作为显式覆盖。

**复盘**：已沉淀 [postmortem 009](../postmortem/009-cookie-env-shadowing.md)（同一问题 2026-08-09 曾出现过一次）。

**落地**：

- 新增 `src/utils/envFile.ts`：用 `node:util.parseEnv` 解析文件，不写 `process.env`；缺失/非法文件返回空。
- `src/cli/shared.ts`：`getCookie()` 只读 `--env-file`（默认 `<pwd>/.env`）；`cookieArg` 增加 `--env-file`。
- `src/cli.ts`：移除顶层 `process.loadEnvFile()`；`whoami` 错误信息给出实际 `.env` 路径。
- `capture/`：同样只读 `.env`，`CaptureOptions.envFile` + CLI `--env-file`。
- E2E：新增 `tests/e2e/setup-env.ts`，测试前用 `.env` **覆盖** `process.env.WEIBO_COOKIE`；`vitest.e2e.config.ts` 改为该 setup。
- 单测：`tests/unit/utils/envFile.test.ts`（6 例，含「陈旧环境变量不影响 `.env`」与显式 `--cookie` 优先级）。
- 验证：`node dist/cli.mjs whoami` 在保留旧环境变量的情况下成功返回当前用户；说明 CLI 已不再受环境变量影响。

## 真实 E2E 回归

**第一次全量**：8 passed / 10 failed。归类：

1. **测试断言过期**（真实契约漂移）：
   - `listByUserId()` 已改为 `page` 游标，`sinceId` 为 `undefined`；E2E 仍断言 `typeof sinceId === 'string'`。
   - `favorites` 的 `data` 已是 `{ status, total_number }` 对象；E2E 仍断言 `Array.isArray(raw.data)`。
2. **结构快照工具白名单不完整**：`stripVolatileKeys` 只替换已知 key，`allow_all_comment`、`audio_ability`、`comment_display`、`urank` 等动态值导致快照频繁误报。
3. **Live 数据变化**：时间线、关注列表、用户资料本身在变；快照不应携带这些值。

**修复**：

- `src/utils/structure.ts`：改为**真正只保留结构**——对象保留全部 key，数组只保留首元素，原始值统一归一化为 `<STR>` / `<NUM>` / `<BOOL>` / `null`。字段增删或类型变化会改变 digest，单纯值变化不会。
- E2E 测试统一复用该工具（删除两份本地副本）；`ArchiveService` 的 `schemaDigest` 断言同步更新。
- 修正 `sinceId` → `page` / `hasMore` 断言；修正 favorites `data.status` 断言。
- 新增 `tests/unit/utils/structure.test.ts`（值变化不敏感、字段/类型变化敏感）。

**第二次全量**：`pnpm test:e2e` **18/18 passed**；离线 `pnpm test -- --run` 135 passed / 18 skipped；typecheck / lint / validate:fixtures / build 全绿。

**上游观察（2026-10-19）**：

## 产品裁定：公开关键词搜索暂缓

**关键外部输入**：

- 万条级完整镜像必须靠日期切片（`searchProfile`），page 游标有天花板。
