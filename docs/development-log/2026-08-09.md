## 修复：E2E 离线稳定性（Task 11）

**问题**：默认 `pnpm test` 会跑 `tests/e2e/**` 并因 `.env` 中过期 Cookie 失败 17 个。根因：
1. `vitest.config.ts` 的 `exclude: ['tests/e2e/**']` 被注释 → e2e 文件被默认测试包含
2. e2e 的 skip 逻辑只看 `WEIBO_COOKIE` 存在（`cookie ? describe : describe.skip`），而 Vitest 默认加载 `.env` → 有 cookie（哪怕过期）就跑
3. `.env` 里有 `WEIBO_E2E="1"`，进一步放大误跑

**决策（文档先行）**：不采用「恢复 vitest exclude」的配置方案（用户明确跳过）；改为**显式门控**：
- `WEIBO_E2E` 由 `vitest.e2e.config.ts` 显式设置，**不放入 `.env`**
- e2e 用例仅在 `WEIBO_E2E === '1'` **且** `WEIBO_COOKIE` 存在时运行，否则 `describe.skip`
- 同步更新 `CLAUDE.md` 与 `docs/渐进式开发计划.md` 的 E2E 门控说明

**结果**：默认 `pnpm test` 76 passed | 18 skipped（e2e 全跳）。

## P1 · ArchiveService 断点续传流（A5-A8）

承接 todo A5-A8（归档 MVP 核心交付）。**判别标准**：≤20 行代码 + 1 条 CLI 命令镜像单账号。

### 设计

- **ArchiveService**（`src/services/public/ArchiveService.ts`）：编排层，**不继承 FetcherService**（只编排不直接发请求），构造注入子 Service（轻量接口，便于离线 mock）。
- **流式**：`streamArchive(uid, options?)` → `AsyncIterableIterator<ArchiveItem>`，依次产出 **timeline → reposts → favorites** 三阶段。
  - timeline 用 raw `myMblog` 翻页（since_id 游标），逐条 `new Tweet(item)` 归一化 + `stripVolatileKeys(item)` 结构快照
  - reposts 用 `getReposts`（page 翻页）
  - favorites 用 `getFavorites`（page 翻页）
- **A6 checkpoint**：每个 `ArchiveItem` 携带当前 `checkpoint`（phase/sinceId/lastMblogId/favoritesPage/visitedMblogIds），调用方保存最后一项即可断点续传。
- **A7 结构快照**：`stripVolatileKeys` 从 E2E 提为 `src/utils/structure.ts`（ADR-011），每个 item 携带 `schemaDigest` 作为上游漂移检测器。
- **A8 CLI**：`weibo-sdk archive <uid>` 迭代流，JSON 进度输出 + checkpoint 落盘续传。
- **WeiboSDK 门面**：暴露 `sdk.archive`（注入 tweets/favorites）。

### 关键决策

- timeline 用 raw `myMblog` 而非归一化 `listByUserId`：因为 A7 需要 raw 结构快照，归一化会丢失上游字段；翻页/去重逻辑由 ArchiveService 自己控制。
- ArchiveService 不继承 FetcherService：它的「请求」全部委托给注入的子 Service，保持可测性（mock deps 即可，无需 fake axios）。
- reposts 阶段断点：`lastMblogId` 记录已处理到的微博，续跑时重新翻 timeline 跳过已处理项（timeline 需要重放，但幂等）。

### A5-A8 实施完成

- **A5** `ArchiveService.streamArchive(uid, options?)` → `AsyncIterableIterator<ArchiveItem>`（timeline → reposts → favorites）
- **A6** checkpoint：每 item 携带快照（phase/sinceId/lastMblogId/favoritesPage/visitedMblogIds）；`sinceId` 语义 = 下一页游标（`''` = 已到底，resume 不重翻）
- **A7** `stripVolatileKeys` 提为 `src/utils/structure.ts`（ADR-011）；每 item 携带 `schemaDigest`
- **A8** CLI `weibo-sdk archive <uid>`：NDJSON 进度 + checkpoint 落盘 `.weibo-sdk-archive-<uid>.json` 续传
- 门面：`WeiboSDK.archive`；类型导出 `ArchiveCheckpoint/ArchiveItem/ArchiveStreamOptions/...`
- 测试：ArchiveService.test.ts ×5（串联顺序 / checkpoint 断点续传 / schemaDigest / includeReposts=false / timeline 翻页游标）
