## 真实 API 数据发现的问题

2026-05-16 通过 `.env` 中真实 Cookie 调取微博 API，与当前代码对比发现以下偏差。

### Bug 等级

| # | 问题 | 位置 | 真实值 | 当前声明 | 影响 |
|---|---|---|---|---|---|
| B1 | `since_id` 类型错误 | `mymblog.ts` / `tweet.ts` | `string`（空串 `""`） | `number` | 分页逻辑退化运行但类型声明错误 |
| B2 | `total` 为 `-1` | `mymblog.ts` | `-1`（非范围值） | `number` | `filtered.length < raw.total` 逻辑错误 |
| B3 | `since_id: 0` 做游标 | `TweetService.ts` | `""` 表示无更多 | Number() 转换 | 当前 `Number(raw.since_id ?? 0)` 侥幸正确 |

### Schema 精确度缺口

| Schema | 已声明字段 | 真实字段数 | 覆盖率 |
|---|---|---|---|
| `UserInfoResponseSchema` | 2 (`ok`, `data.user`) | 36（在 user 内） | 极低 |
| `UserDetailsResponseSchema` | 2 (`ok`, `data`) | 13（在 data 内） | 极低 |
| `StatusShowResponseSchema` | ~10 核心字段 | 47+ | 约 20% |
| `MyMblogResponseSchema` | 3 (since_id/list/total) | 7 顶层 + 约 60 每条 | 极低 |

## 真实数据获取操作手册

### 前置条件

```bash
# .env 需包含：
WEIBO_COOKIE="SUB=xxx; XSRF-TOKEN=xxx; ..."
WEIBO_E2E="1"
```

### 常用 API 调用

```bash
source .env
TOKEN=$(echo $WEIBO_COOKIE | sed -n 's/.*XSRF-TOKEN=\([^;]*\).*/\1/p')
UA="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"

# 用户信息
curl -s -H "Cookie: $WEIBO_COOKIE" -H "X-XSRF-TOKEN: $TOKEN" -H "User-Agent: $UA" \
  "https://weibo.com/ajax/profile/info?uid={uid}"

# 微博详情  
curl -s -H "Cookie: $WEIBO_COOKIE" -H "X-XSRF-TOKEN: $TOKEN" -H "User-Agent: $UA" \
  -H "Referer: https://weibo.com/detail/{mblogid}" \
  "https://weibo.com/ajax/statuses/show?id={mblogid}&isGetLongText=true"

# 保存 fixture
curl -s ... > tests/fixtures/raw/{name}.json
```

### 筛选特定变种

```python
import json
with open('mymblog.json', encoding='utf-8') as f:
    data = json.load(f)
for p in data['data']['list']:
    print(p['mblogid'], f"pics={p.get('pic_num',0)}",
          f"retweet={'retweeted_status' in p}",
          f"long={p.get('isLongText', False)}")
```
