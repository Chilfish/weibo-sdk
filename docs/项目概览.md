# 项目概览

## 这是什么

`weibo-sdk` 是一个面向开发者的微博 API 逆向开源 SDK：通过可维护的分层架构，把微博页面/接口返回的"易变 raw JSON"稳定地转换为"契约明确的领域模型"，并提供可组合的服务能力（用户/微博/搜索等）。

项目目标是：**可维护、易理解、开发者体验好**，并且在上游字段/API 频繁变动时，依然能通过契约与测试提供稳定性。

## 架构（分层）

分层目标见 `docs/微博SDK技术规格书_v2.0.md`，核心思想是：

- **客户端层**：`WeiboSDK`（对外门面）
- **服务层**：`UserService` / `TweetService` / `SearchService`（按领域组织 API，均继承 `FetcherService`）
- **基础设施层**：`FetcherService`（HTTP）、`AuthService`（认证）、`RateLimitService`（节流/并发）等
- **数据层**：`types/raw/**`（原始 schema）、`types/domain/**` + `models/data/**`（领域契约与归一化）

当前代码已落地：

- `WeiboSDK → UserService → Fetcher/Auth/RateLimit → User(domain)` 的用户闭环
- `WeiboSDK → TweetService → Fetcher/Auth/RateLimit → Tweet(domain)` 的微博列表闭环（mymblog + show，归一化含 media/pageInfo/geo/retweetedStatus）
- `SearchService` 仍处于占位阶段

### Endpoint 管理模式

API endpoint 定义统一放在 `src/services/endpoints/<domain>.ts`，使用 `defineEndpoint()` 定义：

- `argsSchema`：Zod schema（args 类型从 schema 自动推导）
- `responseSchema`：Zod schema（响应校验，默认 `.loose()` 开放端点模式）
- `buildResource`：构建 `IRequestResource`
- `okPolicy`：控制 ok !== 1 时的错误处理

Service 中只需 `this.request(spec, args)` 即可完成请求 → 校验 → hooks emission → telemetry 全流程。

当前已定义 5 个 endpoint：`USER_INFO`、`USER_DETAILS`（含无 args 的 `myDetails`）、`TWEET_MYMBLOG`、`TWEET_SHOW`。

## 可测试性与开发方式（TDD-first）

本项目要求 **默认测试离线可跑**：

- 单元测试：纯逻辑/模型/normalize（0 IO）
- 组件测试：对 HTTP/时间/睡眠等边界做 mock，覆盖 Fetcher/Auth/RateLimit 与 service 行为
- E2E：需要真实 Cookie + 真实网络的用例必须默认跳过，通过 `WEIBO_E2E=1` 显式开启

测试工具：`tests/testkit/fakeAxios.ts` 提供 `createFakeAxios(handler)` 可代替真实 axios；各测试可按需定义 `FakeClock` / `TelemetryCollector`。

开发流程：先写契约与失败测试（Red），再最小实现（Green），最后重构（Refactor）。详见 `docs/TODO.md` 与 `docs/渐进式开发计划.md`。

## 可观测性（Wide Events）

遵循 `docs/SKILL.md`：核心路径必须能输出"宽事件"（扁平 KV，含 `event_name/timestamp/trace_id` 及关键上下文），覆盖 Happy Path 与 Error Path，并可在测试中断言事件序列与字段完整性。

已落地的事件类型：
- `request_start` / `request_success` / `request_error`（HTTP 请求生命周期）
- `rate_limit_wait`（令牌桶等待）
- `normalize_done`（领域模型归一化完成）

## 快速开始（本仓库）

- 安装：`pnpm install`
- 测试：`pnpm test`
- 构建：`pnpm run build`
- 类型检查：`pnpm run typecheck`

> 若需要运行真实微博请求，请通过环境变量提供 Cookie，并使用专门的 e2e 测试入口（默认不运行）。
